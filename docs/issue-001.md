# 先见系列（第001期）：2026中期选举，共和党会同时失去两院吗？

[← 返回目录](../README.md) · [English](issue-001.en.md)

**原预测：共和党失去众议院71.2%，失去参议院65.6%，同时失去两院59.0%。**

> 这篇是2026年11月11日的历史补录，保留10月31日冻结的原始概率。补录时选举已经发生，不能把本次GitHub公开当作10月31日已经公开的证明。

视频用“特朗普会成为跛脚总统吗？”作为通俗标题，具体预测的是共和党能否保住国会两院控制权。

## 当时为什么这样判断？

**众议院的评级显示民主党有多数路径。** 当时读取的Sabato 10月27日评级汇总为：225席至少倾向民主党、193席至少倾向共和党、17席摇摆，共435席。但评级是分析判断，不是已经赢下的席位。

**参议院存在多条增席路径。** 原研究按全部100席的组织归属计算，而不是只看本次35席改选。民主党组织联盟的原底数是47席，共和党53席；民主党守住原有席位并净增4席，才能达到51席。竞争州调查提供了路径，但不保证这些州同时翻转。

**同一份民调只算一次。** 堪萨斯一份800名可能投票者调查，初问民主党候选人领先3.5个百分点，计入未决定者倾向后只领先2.4个百分点。这是同一调查的不同口径，不能当成两份独立利好，也不能直接外推全国席位。

## 最强反证是什么？

若民主党丢掉一个原有参院席位，即使翻转四席也只有50席。翻转机会与守席风险必须一起看；任何一院仍由共和党组织，联合题就不能算成功。

调查还可能存在共同误差。华邮堪萨斯调查披露，接通电话后登记民主党受访者完成率32%、登记共和党受访者12%。这提示该调查的非应答风险，不是候选人支持率，也不证明全国调查或其他机构有同等偏差。把单州参院调查风险用于判断众院，本身也是原研究的局限。

## 概率是怎么得出的？

当时由AI研究证据、评估每项事实的影响力度，再按重复来源、可信度和相关性降权，逐步更新概率。**这些权重带有主观判断，没有经过大规模历史事件校准，也不是一套已验证的逐席位模拟。**

三个题目分别生成并共享部分材料；“同时失去两院”的59.0%不是两个单院概率相乘。通过数学一致性检查，不等于两院关联假设已被验证。

## AI与当时市场的对照

| 预测事件 | AI原估计 | Polymarket对应合约中间价 |
| --- | ---: | ---: |
| 共和党失去众议院 | **71.2%** | 94.5% |
| 共和党失去参议院 | **65.6%** | 71.5% |
| 共和党同时失去两院 | **59.0%** | 70.5% |

这是**2026年10月31日北京时间15:55左右**保存的历史价格，晚于15:22的预测冻结约33分钟，不是选后报价。市场对应民主党控制的相关合约，其席位归属及独立议员规则与本题的实际组织控制条件有差别，因此属于近似问题对照。

原记录声明市场价格不参与估计；现有资料不足以独立证明生成过程零暴露，所以不把本期宣传为严格零暴露盲测。AI与市场差多少，也不能据此判断谁更准确。

## 后来发生了什么？

美联社在11月5日的说明中记载：美东11月3日23:36判断民主党赢得参院控制，11月4日01:24判断民主党赢得众院控制。这与原预测的倾向方向一致。

**这只是美联社的选举判断，不能等同原题已经正式结算。** 原题的观察点是2026选举形成的新一届国会首次完成两院组织安排，以正式议长、党团归属、组织决议等记录判断；未决或共享控制不能强行归类。新任期从2027年1月3日开始，也不保证当天完成组织。

因此，不能因为这次方向一致，就宣称模型准确率得到验证，或证明某个概率比市场更准。
