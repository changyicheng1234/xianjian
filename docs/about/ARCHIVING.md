# 归档规则

今后每期默认只公开三类核心资料：

1. **中文预测短文**：在GitHub直接阅读，说明预测问题、双方概率、3—5条主要依据、最强反证和关键限制。方法用简短文字解释；PDF按需要附上。
2. **关键来源**：优先5—10条，直接列在文章中，给出原文链接、日期及一句用途说明，同时覆盖支持与反方证据；不另堆完整抓取清单。
3. **预测冻结记录**：记录问题、结算条件、概率、数据截止和冻结时间。视频引用市场时，在报告中附报价、时间和口径即可，不默认公开整本订单簿。

完整数据集、计算代码、逐场预测、详细诊断、内部运行记录与完整研究档案继续保留本地，不默认随视频公开。技术附录另行整理，不以材料数量代替解释清楚。

一般只需一篇含关键来源的文章和一份冻结JSON。PDF、压缩包与配图根据阅读需要提供，不强制每期都加。首页仿照期刊目录，按年、月和期号链接到docs/issue-NNN.md，点开即可读；下载资料放在文末折叠区。

每期独立目录，README只作简短导读。正式包用带期号的不可变Release归档；修正另发新版本，赛后复盘另存，保留原预测及失误记录。第002期已有完整包不删除、不替换，精简规则从后续期目执行。

本地时间、校验码和提交时间不单独证明首次公开时间。GitHub实际公开时间以Release published_at等平台记录核对。

来源保留必要日期和阅读范围，摘要不能冒充全文。材料精简不省略最强反证、重要缺口或版本修正。凭据、内部会话及第三方完整文章/网页/PDF不打包公开。发现错误请在Issues说明期号、文件、来源和建议修正。
